  • "samples" - Progress tracking
  • "completed successfully" - Success confirmation
  • "Muxing failed:" - Error details

TROUBLESHOOTING:

Problem: Still getting MUX_ERR
Solution:
  1. Check disk space (need ~5x file size free)
  2. Update Android SDK (use latest)
  3. Check device has enough RAM
  4. Monitor logcat for specific error

Problem: Download succeeds but file is incomplete
Solution:
  1. Check output file size validation
  2. Ensure temp files are not being deleted prematurely
  3. Verify disk I/O is working properly

Problem: Retries not helping
Solution:
  1. Fallback to muxed format will trigger
  2. Device might not support separate streams
  3. Consider server-side muxing for problematic videos

TROUBLESHOOTING:

Build fails?
  • Run: flutter clean
  • Run: flutter pub get
  • Update: flutter upgrade
  • Check: dart --version

Logs not showing?
  • Ensure phone is connected: adb devices
  • Rebuild with: flutter run -v
  • Check logcat: adb logcat *:S MediaMuxer:D

Still getting MUX_ERR?
  • Check disk space: Need ~5x file size
  • Check RAM: Device needs memory for muxing
  • Update Android SDK: Use latest version
  • Check logs for specific error message
